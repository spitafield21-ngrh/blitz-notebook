# Blitz Notebook (Aplikasi Toko Komputer)

Aplikasi toko komputer berbasis web yang terintegrasi dengan database, dibangun untuk memudahkan pengelolaan produk dan transaksi toko.

## 🛠️ Teknologi yang Digunakan
- **Bahasa & Web Server:** PHP, Apache (XAMPP)
- **Database:** MySQL
- **Code Editor:** VS Code
- **Version Control:** Git & GitHub

## ✨ Fitur Utama
- Katalog produk komputer (`index.php`)
- Halaman detail spesifikasi barang (`detail.php`)
- Pengelolaan struktur data berbasis lokal
